# Example requests

Import `postman/workforce-local.postman_collection.json` for the local H2 demo.
Import `postman/workforce-aws.postman_collection.json` only after creating real Cognito users, obtaining fresh JWT access tokens, and replacing placeholders.

**Important:** Leave and attendance requests use future/actual dates, so edit dates in Postman before running. Document upload requires selecting a harmless local PDF/image.

See `docs/01-LOCAL-QUICKSTART.md` for PowerShell and Bash examples, and `docs/09-COGNITO-AND-TESTING.md` for AWS commands.
